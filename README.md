# Bolo de Chocolate

Página estática com uma receita simples de bolo de chocolate. Ela apresenta o título e uma breve descrição da receita, uma imagem do bolo, a lista de ingredientes e o modo de preparo.

## Tecnologias

- HTML5, para estruturar o conteúdo da página.
- CSS3, para definir a tipografia, o alinhamento e os estilos dos títulos e parágrafos.
- Imagem JPEG, usada para ilustrar a receita.

Não é necessário instalar dependências ou ferramentas de compilação.

## Estrutura de arquivos

```text
.
├── README.md
└── Bolo de Chocolate/
    ├── BoloChocolate.html
    ├── BoloChocolate.css
    └── bolo-chocolate.jpg
```

O arquivo HTML carrega o CSS e a imagem usando caminhos relativos; mantenha os três arquivos da página juntos na pasta `Bolo de Chocolate`.

## Como visualizar no navegador

1. Abra a pasta `Bolo de Chocolate`.
2. Abra o arquivo `BoloChocolate.html` com um navegador, por exemplo, clicando duas vezes nele ou usando a opção **Abrir com**.

A página será exibida localmente, sem precisar de conexão com a internet.
